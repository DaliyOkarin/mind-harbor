# 心港：中文 AI 情绪陪伴原型

Python 3.10+，无需安装依赖。此项目为独立实现，不包含原合作仓库代码。

## 启动

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 填写支持 Chat Completions 协议的模型地址（通常以 `/v1` 结尾）、模型名和密钥。密钥仅保存在本机，不要提交 Git。
3. 在项目目录执行 `python server.py`。
4. 浏览器打开 http://127.0.0.1:8765 。

PowerShell 复制配置：`Copy-Item .env.example .env`。
修改配置后重启服务器。

## 本版功能

中文聊天页面、三种倾听偏好、最多 30 轮上下文、新对话、重复提交保护、失败时保留输入、后端模型调用。回复完整返回后显示，暂未实现逐字流式输出。不会把情绪分类标签当诊断。

## 数据与边界

仅绑定本机地址。聊天记录在页面内存中，刷新清除；服务器不记录聊天正文。模型服务商仍会收到所提交的对话，请自行确认其隐私政策。无账号、长期记忆或数据库。AI 提示词包含危机回应原则，但尚无独立风险评估或专业审查，不能作为医疗或危机服务部署。公开上线前需要身份认证、限流、HTTPS、数据保护、经过评估的危机处理流程。

## 验证

运行 `python -m unittest discover -s tests -v`。自动测试模拟回复函数，验证 HTTP 接口、多轮上下文传递、输入校验和错误信息脱敏，不等同于真实模型的对话质量评估。
